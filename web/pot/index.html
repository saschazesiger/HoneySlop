      Delete all data?

      This permanently deletes all events and IPs. Settings and your password are kept. This cannot be undone.

      Regenerate world?

      A brand new fake machine is generated:

      • all passwords, credentials, API keys and SSH keys change
      • database contents (users, customers, hashes) are replaced
      • attackers with a running session suddenly see a different machine, and secrets they already stole stop working

      Recorded events and IPs are kept. This cannot be undone.
